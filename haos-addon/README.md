# MyRoom

Prototype WebXR multijoueur pour Quest 2, Quest 3 et Quest 3S, dans une même pièce. Serveur pour quatre joueurs et client Three.js servis par Nginx.

Compatible aarch64 / Raspberry Pi 5. Nécessite une origine HTTPS dédiée avec certificat reconnu par les casques. Aucun essai physique Quest ou HAOS effectué à ce stade.

Voir [les instructions](DOCS.md).
